# `css` plugin

CSS skills for AI coding agents: layout fundamentals, modern features, and debugging guidance. Use when writing or fixing CSS.

## Skills

- `css-layout` — Apply CSS layout fundamentals correctly when positioning, sizing, aligning, centering, stacking, or debugging any element. Use whenever writing or fixing CSS that involves display, position, margin, padding, width, height, z-index, flex, grid, sticky/absolute/fixed positioning, centering, overlapping elements, sticky behavior, stacking contexts, or unexpected layout/whitespace issues.

## Compatibility

Works with Claude Code and Cursor.
